## How to use this playlist

1. Copy the full URL for all languages or your preferred language.
2. In VLC, open a network stream; in an IPTV player, add an M3U playlist URL.
3. Refresh the playlist periodically to pick up source changes.

Categories describe channels tagged as **relax** in upstream metadata, not the programme airing right now. These are live channel links, not an on-demand library or an event guarantee. Counts include alternative streams and do not mean every link has been playback-tested.

Source: [iptv-org](https://github.com/iptv-org/iptv). For playback or metadata problems, see the [FAQ](../FAQ.md) or [report an issue](https://github.com/IMAN-Py/open-tv-atlas/issues/new/choose).
